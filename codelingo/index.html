    Centro de Ayuda y Referencia de la Suite

    1. Editor VS Code Multi-Lenguaje

    Soporta Python 3, C, C++, Java y JavaScript. Escribe código o elige plantillas, presiona Ctrl+Enter o "Ejecutar" para compilar y correr con el motor de ejecución en sandbox.

    2. Terminal Linux Bash

    Emula un entorno Linux completo con sistema de archivos virtual persistente. Comandos soportados: ls, cd, pwd, mkdir, rm, touch, cat, echo, grep, whoami, uname, date, neofetch, python3, gcc, clear, etc.

    3. Terminal Windows (PowerShell & CMD)

    Emula el símbolo de sistema de Windows y PowerShell. Comandos soportados: dir, cd, md, del, type, cls, ver, systeminfo, ipconfig, tasklist, Get-Process, etc.

    4. Web Studio (HTML/CSS/JS)

    Edita tu página en tiempo real con recarga instantánea, pruebas en vista móvil/tablet/pantalla completa y consola de depuración web integrada.

    5. Simulador 1: Reconocimiento de Componentes

    Inspecciona la anatomía detallada de placas madre, CPUs, memorias SO-DIMM, heatpipes con turbina y zócalos mediante puntos interactivos (hotspots) y pon a prueba tu conocimiento con exámenes de reconocimiento de hardware.

    6. Simulador 2: Montaje en su Lugar Correspondiente

    Simulador con validación estricta de ranuras y sockets para PC gamer y Notebook CISCO: arrastra o selecciona cada pieza y colócala en su posición exacta. Detecta y rechaza errores técnicos si intentas colocar una pieza en la ranura equivocada.

    7. Simulador 3: Upgrades y Reemplazo de Componentes

    Diagnostica computadoras y laptops lentas u obsoletas con problemas de arranque y bajos FPS. Desmonta las piezas viejas, instala repuestos modernos y comprueba el impacto en tiempo real con benchmarks de FPS, tiempo de booteo y memoria.

    8. Simulador 4: Limpieza y Mantenimiento Técnico

    Taller interactivo de mantenimiento profundo: usa la lata de aire comprimido para expulsar polvo de ventiladores, pasa la brocha antiestática por ranuras, desatornilla el disipador, disuelve la pasta térmica reseca con alcohol isopropílico al 99.9% y aplica una gota calibrada de pasta térmica fresca.
